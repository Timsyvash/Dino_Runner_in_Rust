# Dino_Runner_in_Rust
Я зробив гру DinoSaur на Rust з Bevy.
## Про гру DinoSaur
The Dinosaur Game (також Chrome Dino) — це вбудована браузерна гра у браузері Google Chrome. Гравець керує піксельним тираннозавром, що біжить ландшафтом із боковою прокруткою, уникаючи перешкод, намагаючись набрати якомога більше очок. Гру створено Себастьєном Габріелем 2014 року, вона вмикається при натисканні пробілу, коли браузер не має доступу до інтернету.
Основні правила та управління: 
-Запуск: Натисніть пробіл, стрілку вгору або торкніться екрана, щоб почати. 
​​-Дії: Динозавр біжить сам. Потрібно стрибати (\(\uparrow \) або пробіл), щоб перестрибнути кактуси, і пригинатися (\(\downarrow \)), щоб ухилитися від птеродактилів.
-Програш: Гра закінчується при зіткненні з будь-якою перешкодою.
-Особливості: Гра стає швидше, а після 700 оч. Максимальний рахунок - 99999, після чого він обнулюється.
Гра автоматично припиняється, якщо згорнути вкладку або натиснути клавішу Alt.
## Про Rust.
Rust — це сучасна компільована мова програмування загального призначення, орієнтована на безпеку, швидкість і паралелізм. Вона забезпечує високу продуктивність, порівнянну з C/C++, завдяки управлінню пам'яттю через механізм «володіння» (ownership) без використання збирача сміття. Популярна для системного програмування, вбудованих систем (embedded), вебсервісів та WebAssembly. 
Де застосовується Rust:
-Системне програмування: Розробка операційних систем, драйверів, ядер (наприклад, ядро Linux).
-Вебсервіси та Backend: Створення швидких мережевих додатків та мікросервісів.
-Embedded (Вбудовані системи): Програмування мікроконтролерів.
-WebAssembly (Wasm): Високопродуктивні додатки в браузері.
-Game Development: Розробка ігрових рушіїв. 
Чому Rust популярний:
-Найулюбленіша мова: За результатами опитувань Stack Overflow, Rust займає перше місце серед розробників протягом багатьох років поспіль.
## Про Bevy.
Bevy — це сучасний ігровий рушій з відкритим вихідним кодом, написаний мовою програмування Rust Reddit 0.9. Він орієнтований на розробку даних (data-driven) та використовує архітектуру ECS (Entity-Component-System). Bevy відрізняється високою продуктивністю, модульністю та використовується для створення 2D/3D ігор. 
Основні характеристики Bevy:
-Мова Rust: Забезпечує безпеку пам'яті та високу швидкість виконання.
-ECS-архітектура: Використовує сутність-компонент-система, що дозволяє легко масштабувати та гнучко керувати ігровими об'єктами.
-Відкритий код: Розвивається спільнотою, безкоштовний для використання.
-Data-driven: Логіка ігор будується навколо даних, що спрощує код та розширення функціоналу. 
Також, bevy — це англійське слово, що означає "зграя", "група" або "збори".
